**Техносервис - Учет заявок на ремонт**

WPF-приложение для автоматизации работы сервисного центра по приёму, учёту и обработке заявок на ремонт оборудования.

**Описание проекта**

Приложение "Техносервис" обеспечивает полный цикл управления заявками на ремонт от создания заявки с автоматической генерацией уникального номера и привязкой к клиенту, оборудованию и типу неисправности до управления справочниками (клиенты, оборудование, сотрудники, запчасти), просмотра статистики и генерации QR-кода с полной информацией о заявке для быстрого доступа через мобильные устройства.

**Основные функции**

Создание, редактирование и удаление заявок на ремонт

Автоматическая генерация уникального номера заявки (RR-ГГГГММДД-ЧЧММСС)

Привязка заявок к клиентам, оборудованию и типам неисправностей

Управление справочниками: клиенты, оборудование, сотрудники, запчасти

Генерация QR-кодов для заявок с полной информацией

Фильтрация и поиск заявок

Просмотр статистики по заявкам и сотрудникам

Валидация ввода и обработка исключительных ситуаций

**Технологии**
Язык программирования	C#
Платформа	.NET Framework, WPF
База данных	Microsoft SQL Server
Генерация QR-кодов	QRCoder
Работа с изображениями	System.Drawing
